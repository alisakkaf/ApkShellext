# Security Policy

## Supported Versions

Only the latest release version of **ApkShellext** is supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:       |

## Reporting a Vulnerability

We take the security of our application seriously. If you find a security vulnerability, please do not disclose it publicly or raise a public issue. Instead, report it directly through the following channels:

* **Email:** Please send an email to the developer at **ali@alisakkaf.com** with details of the vulnerability.
* **Response Time:** We will acknowledge receipt of your report within 48 hours and work on a resolution as quickly as possible.
